## 🌟 Overview

**Shachin Portfolio** (`shachin.pro`) is a production-grade, highly optimized web application showcasing cutting-edge AI systems, deep learning research, 5x hackathon-winning projects, and executive freelance applications. Built with **Next.js 14 App Router**, **React 18**, **Three.js / React Three Fiber**, **Framer Motion**, and **Tailwind CSS**.

### Key Highlights:
- 🤖 **Edith AI Chat Assistant**: Integrated Gemini AI conversational subagent trained on Shachin's biography, project architectures, and technical achievements.
- 🃏 **3D MotionTiles Carousel**: Self-contained 3D depth-stacked video tile carousel with real-time mouse parallax physics, video card memoization (no restarts), and dynamic text highlighting.
- 🆔 **Interactive 3D Lanyard ID Card**: Physics-driven 3D cloth lanyard simulation rendered on a R3F WebGL canvas with dynamic rotation and collision boundaries.
- ⚡ **Zero-Layout-Shift Design System**: Tailored dark-mode glassmorphism, responsive grid layouts, custom scrollbars, and optimized media preloading.

## 🚀 Key Features

### 1. Edith AI Assistant (`/src/components/ChatAssistant.tsx`)
- Context-aware conversational AI assistant powered by Google Gemini API.
- Implements real-time stream processing, message history, suggested prompt pills, and interactive modal dialogs.
- Knowledgeable about Shachin's projects (OrbitXOS, Satellite Error Prediction, SurYah portfolio, etc.) and hackathon wins.

### 2. 3D MotionTiles Project Carousel (`/src/components/MotionTiles.tsx`)
- Depth-stacked card layout with smooth Framer Motion spring physics (`stiffness: 260, damping: 28`).
- Video memoization ensuring seamless background looping without video re-initialization during card switches.
- Mouse coordinate tracking for subtle hover parallax rotation.

### 3. Interactive 3D Lanyard Canvas (`/src/components/Lanyard.tsx`)
- Interactive WebGL 3D ID badge with realistic physics simulation.
- Supports pointer drag interactions, tension constraints, and light reflections.

## 🛠️ Local Development

### Prerequisites
- **Node.js**: `v18.x` or higher
- **npm**: `v9.x` or higher

### 1. Clone the Repository
```bash
git clone https://github.com/Shachin-7/Shachin-portfolio.git
cd Shachin-portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Set Up Environment Variables
Create a `.env.local` file in the root directory:
```env
NEXT_PUBLIC_GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 5. Build for Production
```bash
npm run build
npm run start
```
